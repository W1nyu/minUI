이게 무엇인가

미니은행은 실제 은행 앱처럼 생긴 데모입니다. MinUI(자주 쓰는 기능만 큰 카드로 남기고 나머지는 말로 불러내는 UI 레이어)를 실제로 돈이 오가는 화면 위에서 검증하려고 만들었습니다.

실제 금융 서비스가 아닙니다

실계좌·마이데이터·실제 인증과 연결되지 않습니다. 계좌번호와 이름은 모두 지어낸 것이고, 이체는 이 저장소 안의 가상 원장에서만 일어납니다. 비밀번호를 확인하지 않습니다 — 로그인 화면의 키패드는 은행 앱의 모양을 보여 주는 시늉이라 무엇을 눌러도 들어갑니다.

데모의 핵심은 헤더의 [기본 UI] / [쉬운 모드] 스위치입니다. 두 모드는 같은 백엔드, 같은 화면 컴포넌트를 쓰고 UI 레이어만 다릅니다. 그래야 비교에서 UI 외의 변수가 통제됩니다.

1

준비물

Node와 pnpm만 있으면 시작할 수 있습니다. Docker와 Java는 「계정계까지」 갈 때만 필요하니, 없다면 아래 3A 갈래로 가세요.

무엇필요한 버전언제 필요한가
Node.js 20 이상 항상
pnpm 9 이상 항상 (npm 아님)
Docker Desktop — 계정계까지 갈 때만
JDK 26 계정계까지 갈 때만
Chrome — 음성으로 찾기를 쓸 때

가진 것부터 확인합니다

터미널(PowerShell 또는 터미널 앱)을 열고 하나씩 쳐 보세요.

node -v      # v20.0.0 이상이면 됩니다
pnpm -v      # 숫자가 나오면 됩니다

pnpm에서 "명령을 찾을 수 없다"가 나오면 한 번만 설치하면 됩니다 — npm install -g pnpm

계정계까지 갈 생각이라면 두 개를 더 확인합니다.

java -version      # version "26" 이 보여야 합니다
docker version     # Server 줄이 보이면 Docker가 켜져 있는 겁니다

Docker Desktop은 실행되어 있어야 합니다

설치만 해 두고 켜지 않으면 docker version의 Server 줄이 안 나옵니다. 작업 표시줄에서 Docker Desktop을 먼저 실행하고, 고래 아이콘이 멈춤 없이 안정될 때까지 기다리세요.

2

처음 한 번만

저장소를 받은 뒤 딱 한 번 실행합니다. 다음부터는 건너뛰어도 됩니다.

저장소 최상위 폴더에서 (minUI/)

pnpm install

패키지를 내려받는 데 1~3분 걸립니다. 끝나면 프롬프트가 다시 돌아옵니다. 경고 몇 줄이 지나가는 것은 정상입니다.

왜 npm이 아니라 pnpm인가

이 저장소는 여러 패키지가 한 폴더에 있는 워크스페이스입니다. pnpm --filter frontend dev처럼 "이 패키지만" 지목하는 문법을 쓰기 때문에 npm으로는 그대로 돌지 않습니다.

3

어느 갈래로 켤까

두 갈래가 같은 화면을 보여 줍니다. 다른 것은 이체가 어디에 기록되느냐뿐입니다. 처음이라면 왼쪽을 고르세요.

추천 · 2분

3A 브라우저만

이체가 브라우저 탭 안의 가상 원장에 기록됩니다. 탭을 닫으면 사라집니다.

  • Docker·Java 필요 없음
  • 터미널 1개
  • 모든 화면이 그대로 동작

전체 구성 · 10분

3B 계정계까지

이체가 PostgreSQL의 복식부기 원장에 기록됩니다. 껐다 켜도 남습니다.

  • Docker + JDK 26 필요
  • 터미널 3개
  • 서버측 잔액·동시성까지 확인
3A

브라우저만으로 켜기

  1. 터미널을 열고 저장소 폴더로 갑니다

    어디서든

    cd minUI

    폴더를 받은 위치에 맞춰 경로를 바꾸세요.

  2. 프런트를 띄웁니다

    minUI/

    pnpm --filter frontend dev

    Local: http://localhost:5173/ 같은 줄이 나오면 성공입니다. 이 터미널은 닫지 마세요 — 닫으면 앱이 꺼집니다.

  3. 브라우저에서 엽니다

    http://localhost:5173

    「누구로 볼까요?」 화면이 뜨면 끝났습니다. 4번 시연 대본으로 넘어가세요.

여기까지가 전부입니다

이 갈래에서도 로그인, 12명 전환, 이체, 안심 점검, 음성, 읽어 주기가 모두 동작합니다. 빠지는 것은 서버측 원장 하나뿐입니다.

3B

계정계까지 켜기

터미널 3개를 씁니다. 각각 하나씩 계속 켜 두어야 하므로, 하나에서 끝내고 다음으로 넘어가는 게 아니라 새 터미널을 열어 진행합니다.

  1. 데이터베이스를 띄웁니다 터미널 1

    minUI/

    docker compose -f backend/compose.yaml up -d

    처음이면 PostgreSQL 이미지를 내려받느라 1~2분 걸립니다. Container minui-bank-db Started가 나오면 됩니다. -d는 백그라운드로 돌린다는 뜻이라 이 터미널은 다시 쓸 수 있습니다.

  2. 백엔드를 띄웁니다 터미널 2

    minUI/backend/

    cd backend
./gradlew bootRun

    첫 실행은 3~5분 걸립니다 — Gradle과 의존성을 내려받기 때문입니다. 다음부터는 10초쯤입니다. 아래 두 줄이 보이면 준비된 것입니다. 

    Started BackendApplication in 8.3 seconds
시연 데이터 판 5: 사람 12명 · 계좌 20개

    Windows PowerShell에서 ./gradlew가 안 되면 .\gradlew.bat을 쓰세요.

  3. 프런트를 백엔드에 붙여 띄웁니다 터미널 3

    minUI/ · PowerShell

    $env:VITE_API_BASE_URL = "http://localhost:8080"
pnpm --filter frontend dev

    minUI/ · macOS · Linux · Git Bash

    VITE_API_BASE_URL=http://localhost:8080 pnpm --filter frontend dev

  4. 브라우저에서 엽니다

    http://localhost:5173

    어느 원장에 붙었는지 확인하는 법: 김순자로 들어가 잔액을 봅니다. 1,618,500원이면 PostgreSQL, 1,243,500원이면 브라우저 원장입니다. 두 원장이 잔액을 만드는 방법이 달라서 그렇습니다.

무엇주소누가 씁니까
프런트localhost:5173사람이 보는 화면
백엔드localhost:8080프런트가 부릅니다
PostgreSQLlocalhost:5433백엔드가 부릅니다

데모 데이터가 다시 깔릴 때가 있습니다

시연용 사람 표(shared/contracts/demo-users.json)의 판 번호가 올라가면, 백엔드가 뜰 때 가상 원장을 지우고 다시 깝니다. 로그에 경고로 남습니다. 지워지는 것은 이 데모의 계좌·거래 기록뿐입니다.

3분이면 됩니다

4

시연 대본

이 데모가 보여 주려는 것을 가장 짧게 밟는 길입니다. 돈을 보내고, 받는 사람으로 서서, 도착한 것을 봅니다.

  1. 김순자로 들어갑니다

    「고령」 칸의 김순자를 누르고, 키패드에서 아무 숫자나 여섯 번 누릅니다. 무엇을 눌러도 들어갑니다.

  2. 잔액을 봅니다 — 탭 0회

    큰 카드 넉 장 중 잔액 보기 카드에 금액이 이미 떠 있습니다. 눌러서 들어갈 필요가 없다는 것이 이 UI의 요점입니다.

  3. 박정호에게 3만원을 보냅니다

    계좌 이체 카드 → 받는 분에서 박정호 월급 → 금액 30000 → 내용 확인하기.

    확인 화면에서 「이 분께는 처음 보내시네요」가 뜹니다. 막지 않고 확인만 한 번 더 받는 것이 안심 점검의 방식입니다. 체크 후 보내기.

  4. 박정호로 갈아탑니다

    화면 위쪽 진행자용 — 다른 사람으로 바로 보기에서 박정호를 고릅니다. 번호를 다시 묻지 않습니다.

  5. 도착한 것을 봅니다

    잔액이 1,900,000원(1,870,000 + 30,000)이고, 거래 내역에 김순자 +30,000원이 있습니다.

여기가 이 데모의 핵심입니다

원장은 하나이고 보는 자리만 사람마다 다릅니다. 보낸 돈이 받는 사람의 화면에 실제로 도착해 있다는 것 — 그것을 보여 주려고 로그인을 만들었습니다.

덧붙여 볼 만한 것

말로 찾기를 누르고 글로 자동이체 안 나가게 해야 하는데 라고 쳐 보세요. 카드에 없는 메뉴를 구어체로 부르는 것이 MinUI의 두 번째 축입니다.

기본 UI로 전환해 같은 이체를 해 보세요. 화면 품질이 아니라 단계 수가 다르다는 것이 드러납니다.

5

화면에 있는 것들

어디를 눌러야 나오는지 함께 적었습니다. 쉬운 모드는 그 모드에서만 보인다는 뜻입니다.

누구로 볼까요 첫 화면

고령·중년·청년·상점으로 나눈 12명 중 하나를 고릅니다. 고른 사람의 통장·거래내역· 자동이체·입금예정만 보입니다.

비밀번호를 확인하지 않습니다. 키패드는 은행 앱의 모양을 보여 주는 시늉입니다.

기본 UI / 쉬운 모드 헤더

이 데모의 전부입니다. 두 모드가 같은 백엔드와 같은 화면 컴포넌트를 쓰고 UI 레이어만 다릅니다.

기본 UI는 대조군입니다 — 배너·계좌 카드·아이콘 격자·탭바로 실제 은행 앱 구조를 따랐습니다. 일부러 못 만들지 않았습니다.

큰 카드 넉 장 쉬운 모드

잔액은 카드에 이미 떠 있어 탭 0회로 읽힙니다. 카드가 왜 그 자리인지는 아래 「왜 이렇게 보이나요?」가 답합니다.

말로 찾기 쉬운 모드

카드에 없는 21개 메뉴를 구어체로 부릅니다. Chrome에서 마이크 권한을 주면 음성이 실제로 동작하고, 없거나 지원되지 않으면 같은 화면의 텍스트 입력으로 똑같이 찾을 수 있습니다.

한 번 헤맨 말로 끝내 메뉴를 찾아내면, 그 말이 이 기기에서 그 메뉴의 이름이 됩니다. 다음부터는 한 번에 나옵니다.

보내는 통장 고르기 이체 화면

통장이 둘 이상인 사람에게만 나타납니다. 하나뿐인 사람에게 고르는 칸을 보이면 단계만 늘어나기 때문입니다.

보내기 전에 확인해 주세요 이체 확인

처음 보내는 분, 평소보다 큰 금액, 방금 같은 곳에 같은 금액, 같은 이름의 받는 분, 늦은 밤, 남는 잔액 — 여섯 가지를 결정론 규칙으로 봅니다.

막지 않습니다. 확인 표시를 하나 더 받을 뿐이고 겁을 주지도 않습니다.

연습해 보기 상단 띠

끝까지 해 보되 아무것도 움직이지 않습니다. 가상 원장조차 건드리지 않습니다. 켜져 있는 동안 배지가 화면에서 사라지지 않습니다 — 켜 둔 것을 잊고 진짜로 보냈다고 믿는 것이 가장 나쁜 결과이기 때문입니다.

전체 계좌 조회 전체 메뉴

내 통장을 고르면 그 통장의 최근 내역이 아래에 붙습니다. 여기서 고른 통장이 거래 내역과 이체의 기본 출금 통장이 됩니다.

글씨 크기 · 진하게 전체 메뉴

배율 하나로 화면의 모든 글자가 함께 커집니다(3단계). 고대비는 색만 바꾸고 배치는 그대로 둡니다 — 대비를 켰다고 자리가 달라지면 익힌 것을 다시 배워야 합니다.

읽어 주기 확인 · 내역

확인 화면과 이번 달 요약을 소리로 읽습니다. 계좌번호는 끝 네 자리만 읽습니다 — 화면은 혼자 보지만 소리는 옆 사람도 듣습니다.

이번 달 요약 거래 내역

목록 맨 위 두 문장. 스무 줄을 훑어 스스로 더하지 않아도 됩니다. 모델이 아니라 원장에서 계산하므로 같은 달에 늘 같은 문장이 나옵니다.

왜 이렇게 보이나요? 홈 카드 아래

카드가 왜 그 자리인지 답하고, 기억해 둔 말을 보여 주고 지웁니다. 개인화가 조용한 것과 깜깜한 것은 다릅니다.

AI 도우미 끄고 보기 상단 띠

시연 중에 누르면 같은 질의가 되묻기로 내려갑니다. 끄는 것은 바깥 중계기이지 기기 안의 것이 아닙니다 — 로컬 검색·구워 둔 뜻풀이·안심 점검은 그대로 돕니다.

진행자용 빠른 전환 상단 띠

사람을 갈아 끼웁니다. 키패드를 거치지 않습니다 — 시연 중 왕복이 잦은데 매번 여섯 자리를 누르면 그 시간이 전부 대본 밖의 시간이 됩니다.

AI가 쓴 문장이 안 보인다면

확인 화면의 안내 문장 일부는 외부 모델이 씁니다. API 키가 없으면 고정 문구로 조용히 내려갑니다 — 고장이 아니라 설계입니다. 「이해 지원」과 안심 점검은 키 없이도 그대로 돕니다.

끄기

켠 순서의 반대로 내립니다.

프런트와 백엔드

각 터미널에서 Ctrl + C를 누릅니다. Windows에서 "일괄 작업을 끝내시겠습니까?"가 뜨면 Y를 칩니다.

minUI/backend/ — Gradle 데몬까지 내리려면

./gradlew --stop

데이터베이스

minUI/

docker compose -f backend/compose.yaml down

데이터는 남습니다. 다음에 켜면 이체 기록도 그대로입니다.

데이터까지 지우고 처음 상태로

docker compose -f backend/compose.yaml down -v

-v는 되돌릴 수 없습니다

그동안의 가상 이체 기록이 전부 지워집니다. 다음에 켜면 데모 데이터가 처음 상태로 다시 깔립니다 — 시연 전에 깨끗하게 만들고 싶을 때 쓰세요.

브라우저 원장은 알아서 사라집니다

3A 갈래에서 한 이체는 브라우저 탭 안에만 있습니다. 탭을 닫으면 사라지고, 화면 위 가상 원장 초기화 버튼으로도 되돌릴 수 있습니다.

8

안 될 때

Port 8080 was already in use

백엔드를 껐는데도 Java 프로세스가 살아남아 포트를 잡고 있는 경우입니다. 오류 메시지 맨 위는 Spring 초기화 실패로 보여서 방금 고친 코드를 의심하게 되는데, 원인은 그게 아닙니다.

PowerShell

$p = (Get-NetTCPConnection -LocalPort 8080 -State Listen -ErrorAction SilentlyContinue).OwningProcess
if ($p) { $p | ForEach-Object { Stop-Process -Id $_ -Force } }

5173·5174 포트도 같은 방법으로 비웁니다 (숫자만 바꾸세요).

Port 5173 is in use, trying another one…

이미 프런트가 떠 있다는 뜻입니다. vite가 5174로 옮겨 뜨므로 그 주소로 들어가거나, 위 방법으로 5173을 비우고 다시 띄우세요.

docker 조회는 되는데 up이 멈춰 있습니다

docker ps는 답하는데 docker compose up이 한 줄도 없이 멈춰 있다면 Docker 엔진이 정지한 것입니다. 캐시가 조회에만 답하고 있어서 멀쩡해 보입니다.

Docker Desktop과 관련 프로세스를 종료한 뒤 다시 실행하세요. docker desktop restart는 같은 백엔드를 거치므로 함께 멈춥니다.

화면이 하얗고 아무것도 안 나옵니다

  • pnpm install을 했는지 확인하세요.
  • 터미널에 빨간 오류가 있는지 보세요.
  • 브라우저에서 F12 → Console 탭의 오류를 확인하세요.

잔액이 예상과 다릅니다

어느 원장에 붙었는지부터 보세요. 김순자 기준 1,618,500원은 PostgreSQL, 1,243,500원은 브라우저 원장입니다. 그 밖의 값이면 그동안 한 이체가 반영된 것입니다.

마이크가 동작하지 않습니다

Chrome에서 주소창 왼쪽 자물쇠 → 마이크 권한을 허용하세요. 지원하지 않는 브라우저에서는 같은 화면의 텍스트 입력으로 똑같이 찾을 수 있습니다 — 음성 없이 못 쓰는 앱이 되지 않게 만들어 뒀습니다.

./gradlew가 실행되지 않습니다

  • Windows PowerShell에서는 .\gradlew.bat을 쓰세요.
  • macOS·Linux에서 권한 오류가 나면 chmod +x gradlew.
  • backend 폴더 안에서 실행해야 합니다.

Git Bash에서 MINUI_BASE=/를 주지 마세요

경로 변환이 /를 C:/Program Files/Git/로 바꿔 버려 빌드는 성공하는데 자산 경로가 깨집니다. 배포용 빌드는 PowerShell에서 $env:MINUI_BASE = "/"로 주세요.
